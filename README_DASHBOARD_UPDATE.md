## 🐛 Troubleshooting

### Charts not showing?
- Clear browser cache (Ctrl+Shift+R)
- Refresh page
- Try a different browser

### Prices show wrong currency?
- Hard refresh (Ctrl+Shift+R)
- Clear cookies
- Reload page

### Tables not displaying correctly?
- Check zoom level (should be 100%)
- Refresh page
- Check on different browser
